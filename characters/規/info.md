# 規 (Rule / Compasses)

## 1. 字源研究 (Etymology)
- **結構**：夫 (fu) + 見 (jian)。
- **本義**：圓規。在古代，由「矢」（測量工具）與「見」（觀察）組成。後「矢」形變為「夫」。
- **演變邏輯**：
  - **夫 (矢/夫)**：古代用於測量、對齊的工具，這裡引申為基準、尺度。
  - **見 (見)**：觀察、對位、審視。
- **綜合語義**：手握圓規或標竿進行視察，引申為「規則」、「法度」、「範圍」。

## 2. 視覺開發概念 (Visual Concept)
- **色調**：典雅金石風，深青色配灑金背景。
- **核心構圖**：
  - 左側：**夫** (Adult Male / Tool Base) - 穩固、正直。
  - 右側：**見** (Eye / Observing Man) - 銳利的大眼，強調對標準的審視。
- **動態建議**：呈現「眼」看向「尺度」的視覺對位感。
